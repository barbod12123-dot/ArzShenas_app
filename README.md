# ارزش‌شناس | Arzshenas — نسخه‌ی کاتلین (Android / Jetpack Compose)

این پروژه، تبدیل کامل اپلیکیشن پایتونی (Flet) «ارزش‌شناس» به یک اپ بومی اندروید با
**Kotlin + Jetpack Compose** است. تمام قابلیت‌های نسخه‌ی اصلی حفظ شده‌اند:

## قابلیت‌های پیاده‌سازی‌شده (بدون هیچ حذفیاتی)
- ۵ تب: خانه، کریپتو، طلا، ارزها، تنظیمات (با Bottom Navigation)
- دریافت لحظه‌ای قیمت ارزهای دیجیتال از **CoinGecko**
- دریافت نرخ ارزهای جهانی از **exchangerate-api**
- دریافت طلا/سکه/دلار آزاد ایران با همان اولویت سه‌گانه‌ی نسخه‌ی اصلی:
  ۱. دانلود از گیت‌هاب (Navasan-API) → ۲. BRSAPI → ۳. داده‌ی نمونه (Fallback)
- ذخیره‌سازی محلی فایل‌های دانلودشده از گیت‌هاب (fiat.json / gold.json) درست مثل نسخه‌ی پایتون
- کش کردن آخرین داده‌ی موفق (SharedPreferences) برای حالت آفلاین + بنر «اتصال اینترنت برقرار نیست»
- جست‌وجو در تب کریپتو و تب ارزها
- تبدیل واحد پول پایه بین تومان و دلار
- دو زبانه (فارسی RTL / انگلیسی LTR) با تعویض کامل جهت رابط کاربری
- دو پوسته (تیره/روشن) با همان پالت رنگی طلایی-مشکی نسخه‌ی اصلی
- به‌روزرسانی خودکار هر ۵ دقیقه + دکمه‌ی به‌روزرسانی دستی
- اعلان (Snackbar) هنگام تغییر قیمت طلا/دلار بیش از ۱.۵٪
- صفحه‌ی «درباره برنامه»
- ذخیره‌ی تنظیمات کاربر (زبان، تم، واحد پول) به‌صورت پایدار

## چرا Jetpack Compose؟
«کاتلین» زبان برنامه‌نویسی رسمی اندروید است؛ برای رسیدن به بهترین UI بومی (که در
درخواست شما خواسته شده)، Jetpack Compose — مدرن‌ترین فریم‌ورک رابط کاربری اندروید —
انتخاب شد (معادل مستقیم Flet ولی کاملاً بومی و پرکاربردتر).

## ساختار پروژه
```
app/src/main/java/com/sirbarbod/arzshenas/
├── MainActivity.kt          # نقطه‌ی ورود، Scaffold، ناوبری پایین، بنر آفلاین
├── AppViewModel.kt           # وضعیت برنامه، رفرش خودکار، اعلان تغییر قیمت
├── data/
│   ├── Models.kt              # مدل‌های داده + لیست ارزها و اقلام طلا
│   ├── DataService.kt         # ارتباط با CoinGecko / exchangerate-api / GitHub / BRSAPI + کش
│   ├── Translations.kt        # دیکشنری دوزبانه fa/en
│   └── Formatters.kt          # فرمت اعداد (جداکننده هزارگان و قیمت)
└── ui/
    ├── theme/Theme.kt & Color.kt   # تم طلایی/مشکی + پشتیبانی فونت وزیرمتن
    └── screens/                    # ۵ صفحه‌ی Home / Crypto / Gold / Currency / Settings
```

## چگونه اجرا کنم؟
1. پروژه را در **Android Studio (Koala یا جدیدتر)** باز کنید (پوشه‌ی ریشه همین پوشه است).
2. صبر کنید Gradle Sync کامل شود (نیاز به اینترنت برای دانلود وابستگی‌ها دارد).
3. روی یک شبیه‌ساز یا گوشی متصل، دکمه‌ی Run را بزنید.

## نکات مهم
- **فونت وزیرمتن**: طبق راهنمای `app/src/main/res/font/README.txt` فایل‌های فونت را
  اضافه کنید تا دقیقاً مثل نسخه‌ی اصلی نمایش داده شود. تا قبل از آن، برنامه با فونت
  پیش‌فرض سیستم بدون خطا اجرا می‌شود.
- **کلید BRSAPI**: در `DataService.kt` (ثابت `BRSAPI_KEY`) قرار دارد؛ در صورت نیاز
  کلید خودتان را جایگزین کنید.
- **آیکون برنامه**: یک آیکون ساده‌ی طلایی/مشکی به‌صورت پیش‌فرض قرار داده شده؛
  در صورت تمایل آن را در `app/src/main/res/drawable/ic_launcher_foreground.xml`
  تغییر دهید یا از Image Asset Studio در Android Studio آیکون دلخواه بسازید.
- تمام دامنه‌های شبکه‌ی مورد نیاز (CoinGecko، exchangerate-api، raw.githubusercontent.com،
  brsapi.ir) در `AndroidManifest.xml` با مجوز اینترنت فعال شده‌اند.

ساخته‌شده بر پایه‌ی نسخه‌ی اصلی Flet — توسط SIRBARBOD.
